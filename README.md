# GoBeyond Innovations

Next.js + Tailwind CSS + Framer Motion marketing site for GoBeyond Innovations and IBM Skills Academy.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Structure

- `app/` - App Router page, layout, and global Tailwind styles
- `components/` - reusable header, footer, and scroll-driven curriculum journey
- `data/` - typed course curriculum content
- `public/` - company and IBM brand assets, plus classroom imagery

## Verification

```bash
npm run build
```
